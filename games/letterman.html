Game mode

Letterman

A hangman-style challenge where you guess letters to uncover French words.

Back to games

How to play

  • Start a round and read or listen to the clue.
  • Guess letters to reveal the hidden French word.
  • Avoid too many incorrect guesses before time or attempts run out.
  • Complete all words in the round to finish.

Available settings

  • Game Level: adjusts word length, round size, and timer pressure.
  • Clue Type: choose how clues are shown (for example pronunciation/topic-based options).
  • Accents Optional: allow accent-insensitive entry.
  • Keyboard Layout: choose the on-screen layout for letter entry.
